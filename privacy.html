Какие данные получает приложение

После согласия владельца Google предоставляет приложению доступ только для чтения данных YouTube и YouTube Analytics. Приложение получает идентификатор и название канала, сведения о видео и плейлистах, описания, теги, даты публикаций, счётчики и агрегированные отчёты о просмотрах и источниках трафика.

Для продолжения разрешённого доступа используются OAuth-токены. Пароль аккаунта Google приложение не получает. Текущие разрешения не предоставляют доступ к модерации комментариев; их расширение не предусмотрено.

Использование и передача

Данные используются только для журнала, проверки публикаций и анализа показателей собственного канала. Они не продаются, не используются для рекламы и не предназначены для обучения универсальных моделей искусственного интеллекта.

Журнал и отчёты хранятся на компьютере владельца. При работе владельца с выбранным им помощником Codex необходимые данные могут обрабатываться этим сервисом для выполнения его запроса. Это не означает публикации отчётов на этом сайте. Владелец должен предоставлять помощнику только сведения, необходимые для своей работы; OAuth-токены и клиентский секрет не передаются в чат.

Использование и передача информации, полученной из Google API, должны соответствовать Google API Services User Data Policy, включая требования Limited Use. Передача для продажи данных, рекламного профилирования или обучения универсальных моделей не допускается.

Хранение и защита

История отчётов сохраняется для сравнения показателей до удаления владельцем. OAuth-токены защищены Windows DPAPI и доступны тому же пользователю Windows. Доступ к компьютеру и его резервным копиям контролирует владелец. Публичный сайт не содержит токенов, клиентского секрета или частного журнала.

Отзыв доступа и удаление

Владелец может отозвать доступ приложения в настройках аккаунта Google. Это прекращает последующий доступ через OAuth, но само по себе не удаляет ранее сохранённые локальные отчёты. Для удаления нужно удалить локальные токены, отчёты и соответствующие резервные копии на компьютере владельца.

Вопросы о доступе, исправлении и удалении данных: warhammerlor@gmail.com. При изменении практик обработки документ обновляется с указанием новой даты.
