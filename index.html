WarhammerLorJournal

Личное приложение владельца YouTube-канала WarhammerLor для просмотра статистики и ведения журнала публикаций.

Для чего нужен доступ Google

Приложение читает сведения о видео, плейлистах и показателях канала через YouTube Data API и YouTube Analytics API. Полученные отчёты помогают владельцу отслеживать просмотры и источники трафика.

Запрашиваются только два разрешения: чтение данных YouTube и чтение YouTube Analytics. Приложение не получает разрешений на загрузку или изменение видео, модерацию комментариев и управление аккаунтом Google.

Кто пользуется приложением

Приложение предназначено для владельца канала и запускается на его компьютере. Публичная регистрация и доступ к журналу через этот сайт не предоставляются. Здесь размещены только описание приложения и его документы.
